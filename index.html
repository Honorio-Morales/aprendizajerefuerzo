article Introducción

El problema del CartPole es un desafío clásico de control subactuado donde el objetivo es mantener un poste en equilibrio sobre un carro móvil el mayor tiempo posible.

En este proyecto, modelamos el problema como un Proceso de Decisión de Markov (MDP) y aplicamos algoritmos de Aprendizaje por Refuerzo para resolverlo sin conocimiento previo de las leyes físicas del entorno.

target Objetivos

  • Implementar el algoritmo Q-Learning (Off-Policy, Value-Based).
  • Aplicar técnicas de discretización para manejar el espacio de estados continuo.
  • Desplegar el agente entrenado en una aplicación web interactiva.

architecture Metodología

Se utilizó el entorno CartPole-v1. Como Q-Learning requiere estados discretos (tabulares), se implementó una discretización que divide las 4 variables continuas en 20 "bins" uniformes.

Se usó una política ε-greedy:

  • Tasa de aprendizaje (α): 0.1
  • Factor de descuento (γ): 0.99
  • Decaimiento (ε): 0.995

monitoring Resultados y Desempeño

El agente logró converger exitosamente, evidenciando un aprendizaje continuo a medida que la tasa de exploración disminuía. La política aprendida (explotación) le permite mantener el poste estable de forma indefinida en las pruebas.
